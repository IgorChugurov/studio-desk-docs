# StudioDesk — документация

Сервис расписания, записи, абонементов и управленческого учёта для йога- и танцевальных студий.

Этот репозиторий — единое место документации проекта. Код лежит в соседних репозиториях: `studio-desk-frontend` и `studio-desk-backend`.

## Файлы

| Файл | Что внутри |
| --- | --- |
| [`plan.md`](plan.md) | Контекст, цель, договорённости, стек, границы первой версии, открытые вопросы, что делать дальше. Начинать с него. |
| [`research/market-and-flows.md`](research/market-and-flows.md) | Рынок и сценарии: конкуренты, боли, стандартные флоу, практики gmall. Исследование, не решения. |
| [`research/accounting-and-decisions.md`](research/accounting-and-decisions.md) | Бухгалтерия gmall, OblikFlow, управленческий учёт студии, договорённости по продукту. |

## Как работать с документацией

- Документация отражает утверждённые решения. Пометки: **зафиксировано** — договорённость с автором, **предложение** — ещё не принято, **открыто** — не обсуждалось.
- Исследования (`research/`) — материал для решений, а не сами решения.
- Файлы меняем только с явного согласия автора.
