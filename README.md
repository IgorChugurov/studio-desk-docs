# StudioDesk — документация

Сервис расписания ресурсов, записи клиентов, абонементов и управленческого учёта, служащий модульным ядром единой бизнес-платформы для разных профилей организаций (студии, салоны услуг, автосервисы, клиники, учёт `OblikFlow`).

Этот репозиторий — единое место канонической документации проекта. Код лежит в соседних репозиториях: `studio-desk-frontend` и `studio-desk-backend`.

## Канонические зоны

| Зона | Что внутри |

| [`01-product/`](01-product/README.md) | Профиль продукта, Админка платформы (`/platform`), Админка организации (`/organization`), Каталоги, Расписание, контракты API |
| [`02-design/`](02-design/README.md) | Стандарт проектирования по потокам и правила поверхностей |

| [`04-engineering-rules/`](04-engineering-rules/README.md) | Правила разработки бэкенда и развёртывания |
