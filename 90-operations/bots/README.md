# 90-operations/bots — рабочая зона ботов

**Не канон.** Зона `90-operations/` по `00-governance/documentation-rules.md` каноном не является. Эта папка — рабочие записи ботов-помощников Игоря Чугурова по проекту StudioDesk.

## Кто пишет

- Главный бот проекта (Grok Bot) и его помощники.
- Игорь может править любой файл здесь напрямую.

## Что лежит

| Файл | Что внутри |
| --- | --- |
| `status.md` | Сводка: где проект по каждому разделу и сквозной теме, зеркало статусов work items, расхождения |
| `decisions.md` | Журнал решений, которые явно записаны в каноне, work items или feedback-файлах, со ссылками |
| `notes/main/` | Рабочие заметки главного бота |

## Правила

1. Канон (зоны `00-governance/`, `01-product/`, `02-design/`, `03-architecture/`, `04-engineering-rules/`) боты **не правят**. Найденное расхождение записывается сюда, в `status.md` → «Расхождения», и выносится Игорю.
2. Файлы `90-operations/work-items/` боты не трогают: состояние задачи живёт там и меняется только по процессу `00-governance/work-items.md`. В `status.md` — только зеркало.
3. Пишем только факты из файлов и кода со ссылкой на путь. Чего не знаем — «не знаю» или «не проверено».
4. Здесь ничего не решается: записи отражают решения Игоря, а не заменяют их. Предложения помечаются как предложения.
5. Коммиты — только файлы этой папки, напрямую в `development`, сообщение на английском с префиксом `bots:`.
