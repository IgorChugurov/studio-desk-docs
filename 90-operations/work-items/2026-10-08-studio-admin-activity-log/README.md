# Журнал действий админки студии

## Цель

Согласовать проектную документацию журнала действий админки студии: кто, когда и как менял данные — покупка абонементов, списание занятий, создание залов и остальные такие операции. Сначала обсудить концепции и варианты, как такие журналы обычно устроены и как их показывают, включая отдельную страницу с фильтрами.

## Границы

Границы темы ещё не согласованы. Их называем в обсуждении.

## Этап

`feature-workflow.md`, полный маршрут, этап 2 (обсуждение темы). Ведёт обсуждение с владельцем. Файла канона нет, пока владелец не скажет «тема согласована».
