# API-контракт админки платформы

## Цель

Подготовить и согласовать с владельцем `01-product/platform-admin/api-contract.md` — фаза 1 из `01-product/platform-admin/backend-brief.md`. По ходу обсудить: где живёт документация реализации бэкенда и фронтенда; схему токенов с refresh-токенами и Sign out на основе `opie-admins-pack/template-administration-backend`; пагинацию и структуру `meta` как там же; что возвращает вход под студией.

## Границы

- Реализацию бэкенда (фазы 2–4) не делаем.
- Вход владельцев студий относится к API студии и в этот контракт не входит.
- Канон темы (`overview.md`) не меняем; найденный пробел — останавливаемся и обсуждаем.
- Правка устаревших строк в `backend-brief.md` и любые файлы, кроме этой записи, — только после отдельного «ОК» владельца.

## Этап

`feature-workflow.md`, этап 5 (задание бэкенду, результат — согласованный контракт API). Ведёт бэкенд. По решению владельца идёт параллельно с `2026-10-02-platform-admin-design-review` (этап 4).
