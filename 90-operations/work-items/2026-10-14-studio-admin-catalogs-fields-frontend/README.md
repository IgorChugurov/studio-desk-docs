# Фронтенд новых полей каталога

## Цель

Добавить во фронтенд студийной админки (раздел Catalogs) новые поля каталога, уже реализованные на бэкенде: тип и часовой пояс зала на формах зала; обязательную длительность по умолчанию на форме вида занятия; выбор связи «тренер ↔ виды занятий» на карточке тренера и на карточке вида занятия. Против обновлённого контракта `01-product/studio-admin/catalogs-api-contract.md` и канона `01-product/studio-admin/catalogs.md`.

## Границы

- Недельная сетка расписания на страницах зала и тренера не входит — это `schedule-frontend-brief.md`.
- Новые сущности и эндпоинты не создаются: фронтенд потребляет готовый контракт.
- Удаление зала, тренера, вида занятия; вместимость, цена, признак «группа или один человек» — не входят.
- Бэкенд готов (`2026-10-14-studio-admin-catalogs-schedule-fields`), повторная реализация бэкенда не нужна.

## Этап

`feature-workflow.md`, полный маршрут, этап 6 — задание фронтенду. Ведёт фронтенд.

Предусловия этапа 6: принятый Figma (этап 4) и согласованный контракт API (этап 5). Контракт согласован и обновлён в этой итерации. Перед разметкой проверить наличие принятого Figma для новых полей; если его нет — остановиться и вернуться к дизайну или канону (пробел), не выбирать самому.

Порядок: разметка экранов → «ОК» → реализация → сверка с Figma по свойствам → приёмка. Коммит и пуш только по явной просьбе владельца.
