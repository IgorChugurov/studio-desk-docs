# Стартовый контекст воркспейса и главенство канона

## Цель

Стартовый контекст агента держит канон `studio-desk-docs` одним always-apply файлом `.cursor/rules/00-workspace-core.mdc`. Правила одного репозитория подключаются файлом `.cursor/rules/project.mdc` только при работе с этим репозиторием. Местные README и `docs/` не повторяют канон и не ведут на несуществующие пути.

Пока Фигмы нет, экран собирается по потоку в каноне темы, из `src/shared/ui/` и по уже готовой странице того же типа.

## Границы

- Логин PostgreSQL `studio_api` не переименовывается. `03-architecture/backend-structure.md` в этой задаче не меняется.
- Реестр id поверхностей не создаётся.
- Блок `nextjs-agent-rules` во фронтендном `AGENTS.md` не переписывается.
- Коммит не входит в эту запись, пока владелец отдельно не попросит.
