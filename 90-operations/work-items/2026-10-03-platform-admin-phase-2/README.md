# Фаза 2 бэкенда админки платформы — вход по коду

## Цель

Реализовать в `studio-desk-backend` фазу 2 из `01-product/platform-admin/backend-brief.md`: администратор платформы и вход по коду на e-mail (коды, токены, сессии, Sign out, отзыв сессий) по согласованному `01-product/platform-admin/api-contract.md`.

До реализации согласовать провайдера e-mail для кодов: цена, бесплатный лимит, надёжность (проект пока некоммерческий). Рекомендацию записать в `01-product/platform-admin/backend-brief-feedback.md`.

## Границы

- Только фаза 2. Студии (фаза 3), деактивация, активация и вход под студией (фаза 4) не входят.
- Расхождения с `api-contract.md` не правим молча: фиксируем в feedback и обсуждаем.
- Секреты (ключи провайдера, пароли) не попадают в репозитории, логи CI и чат.
- Коммит только по просьбе владельца, push — отдельной просьбой.

## Этап

`feature-workflow.md`, полный маршрут, этап 5 (задание бэкенду). Контракт API уже согласован в `2026-10-03-platform-admin-api-contract`. Провайдер e-mail — Resend. Вход проверен локально владельцем: код на почту и `accessToken`. Дальше владелец выкладывает на сервер. Ведёт бэкенд. Параллельно с `2026-10-02-platform-admin-design-review` (этап 4).
