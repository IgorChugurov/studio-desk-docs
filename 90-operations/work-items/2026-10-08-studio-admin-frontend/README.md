# Фронтенд админки студии

## Цель

Сделать админку студии во фронтенде по `01-product/studio-admin/frontend-brief.md`: вход, выбор студии, навбар, строка вкладок, пустые разделы, настройки студии и сотрудники. Компоненты берутся из уже перенесённого кита. Чего в `shared` нет, переносится из стартер-кита.

## Границы

- Задание дизайнеру и Figma не делаем.
- Содержимое Schedule, Catalogs, Clients and bookings, Subscriptions и Accounting and reports не делаем: вкладки пустые.
- Роль «тренер», столбец Trainer и связь с каталогом не входят.
- Админку платформы не меняем, кроме разведения хостов, чтобы она продолжала работать.
- Публичный сайт и вход клиентов не входят.
- Деплой фронтенда не входит.

## Этап

`feature-workflow.md`, этап 6 (задание фронтенду). Задание уже принято: `01-product/studio-admin/frontend-brief.md`. Ведёт фронтенд.
