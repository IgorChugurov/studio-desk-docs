# Бэкенд тренеров, видов занятий и описания зала

## Цель

Добавить в API админки студии необязательное описание зала, тренеров и виды занятий по `01-product/studio-admin/catalogs-trainers-backend-brief.md`. У тренера и вида занятий есть имя, необязательное описание и галерея у уже сохранённой записи. У тренера ещё необязательные ссылки Instagram и TikTok. Сначала расширение контракта.

## Границы

- Расписание, вместимость, групповое или индивидуальное занятие, длительность и цена не входят.
- Роль сотрудника «тренер» и связь с карточкой каталога не входят.
- Оплата, промокоды, абонементы и публичный сайт не входят.
- Удаления зала, тренера и вида занятий нет.
- Уже сделанные залы, кроме нового описания, остаются как есть.

## Этап

`feature-workflow.md`, полный маршрут, этап 5 — задание бэкенду. Ведёт бэкенд.

Фазы 1–4 сделаны. Описание зала — миграция `0010_hall_description`. Тренеры и виды занятий с файлами — миграция `0011_catalog_trainers_class_types`. Таблицы владелец подтвердил 2026-10-09.
