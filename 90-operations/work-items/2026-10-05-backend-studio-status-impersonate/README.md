# Бэкенд платформы - деактивация, активация студии и вход под студией

## Цель

Реализовать в API платформы три эндпоинта из `01-product/platform-admin/api-contract.md`: `POST /studios/{id}/deactivate`, `POST /studios/{id}/activate` и `POST /studios/{id}/impersonate` (одноразовый код входа под студией). Фронтенд уже опирается на эти эндпоинты (в живой проверке сейчас 404).

## Границы

- Фронтенд, канон и контракт API не меняем без отдельного «ОК» владельца.
- Решение владельца: в задачу не входят обмен кода передачи в API студии (`POST /api/studio/auth/impersonation/exchange`), отказ во входе в деактивированную студию и поиск студии по хосту для публичного сайта. Они делаются вместе с API студии и публичным API, когда те появятся.
- Отзыв сессий студии при деактивации не делается: таблицы сессий студий ещё нет. Пока деактивация меняет только статус.
- Канон (`authentication.md`, строка о том, что обмен кода делается вместе с админкой платформы) не меняем без отдельного «ОК» владельца.

## Этап

`feature-workflow.md`: реализация бэкенда по принятому контракту (фаза 4 из `backend-brief.md`). Ведёт бэкенд.

## Закрытие

**Результат.** В API платформы (`studio-desk-backend`) добавлены `POST /studios/{id}/deactivate`, `POST /studios/{id}/activate` и `POST /studios/{id}/impersonate`. Деактивация и активация меняют статус и возвращают студию (повтор ничего не меняет, 200). `impersonate` выдаёт код передачи на 60 секунд для студии в любом состоянии; в базе (новая таблица `handoff_code`, миграция `0003`) хранится только хеш. Для неизвестного или неверного `id` ответ 404, без токена 401. В Postman-коллекцию добавлены три запроса. Новых настроек `.env` нет.

**Чем проверено.** `pnpm test:e2e`: 8 файлов, 56 тестов проходят (в том числе 5 новых на эти эндпоинты и тест прав в базе); `typecheck`, `lint`, `format:check` чистые. Живая проверка из фронтенда владельцем не выполнялась на момент закрытия.

**Не входило в задачу (решение владельца), делается с API студии.** Обмен кода передачи в API студии, отказ во входе в деактивированную студию, поиск студии по хосту для публичного сайта, отзыв сессий студии при деактивации (таблицы сессий студий ещё нет). Строки канона и контракта про отзыв сессий и про обмен кода «вместе с админкой платформы» остались без изменений и ждут решения владельца.
