# Перенос дизайн-кита, страница входа и каркас главной админки платформы

## Цель

Перенести дизайн-кит OPIE (токены, шрифты, нужные компоненты из starter-kit) в `studio-desk-frontend` как исходный код проекта, без общего пакета и без конфиг-движков. На нём сделать страницу входа админки платформы (e-mail → код, по `01-product/platform-admin/design-brief.md`, секция «Вход», и `api-contract.md`) и после входа главную страницу админки с каркасом: только навбар с нужными компонентами.

Каркас главной страницы: контейнер всегда высотой с экран, навбар закреплён, содержимое занимает всю свободную высоту. Для страниц списков таблица занимает всю высоту, скролл внутри таблицы; страница редактирования имеет полный скролл. Образец UX: админка шаблонов OPIE (страницы списков); воспроизводить её структуру не обязательно.

Работа идёт по шагам: карта экрана и компонентов → «ОК» → реализация → разбор.

## Границы

- Не делаем список студий, страницу студии, деактивацию, вход под студией: отдельные задачи по `frontend-brief.md`.
- Не переносим конфиг-движки starter-kit (`universal-list`, `form-generation`, `entity-config`, `sdk`) и общий пакет UI. Тёмная тема не входит.
- Переносим только компоненты, нужные этим экранам; остальные по мере следующих задач.
- Канон и контракт API не меняем без отдельного «ОК» владельца.
- Решение владельца: страница делается от задания дизайнеру (`design-brief.md`) и кита, а не от кадров Figma.

## Этап

`feature-workflow.md`, этап 6 (задание фронтенду) с отклонением по решению владельца: вместо принятых кадров Figma основа — `design-brief.md` и дизайн-кит. Начальный шаг: карта экранов и компонентов кита («разметка экрана») → «ОК» владельца. Ведёт фронтенд.

Подготовлено до старта по просьбе владельца: файл шрифта `studio-desk-frontend/src/shared/fonts/general-sans/GeneralSans-Variable.woff2` (скачан с Fontshare, не закоммичен, лицензия `itf_ffl` — владелец проверяет сам).
