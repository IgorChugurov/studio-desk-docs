# 01-product

Продукт StudioDesk: профиль и темы предметной области. Канон пишется по-русски.

| Документ | О чём |
| --- | --- |
| `profile.md` | Профиль продукта: что это, для кого, из чего состоит, архитектурные принципы, границы |
| `platform-admin/overview.md` | Админка платформы: вход, пресеты профилей бизнеса, организации, страницы, сценарии |
| `organization-admin/overview.md` | Админка организации: вход, выбор организации, роли и двойной фильтр доступа, настройки, управление сотрудниками |
| `organization-admin/catalogs.md` | Раздел Catalogs: единый механизм ресурсов (места, специалисты, оборудование, виды работ/услуг) с кубиками |
| `organization-admin/schedule.md` | Раздел Schedule: шаблоны недели, слоты расписания (рабочие записи и закрытое время), статусы, показ и действия |
