# Каталоги админки студии — залы

**Scope:** раздел Catalogs админки студии. Сейчас описаны залы. Тренеры и виды занятий в этом документе только как пустые вкладки.
**Last verified:** 2026-10-08

## Эссе — что это

Catalogs — раздел админки студии. Его видят владелец и администратор. Верхняя строка вкладок не меняется: Catalogs остаётся одной вкладкой (`overview.md`).

Под ней, в области страницы, вторая строка: Halls, Trainers, Class types. Сейчас список и формы есть только у Halls. Trainers и Class types открываются пустой страницей, их вкладка выделена.

Хлебные крошки: название студии, Catalogs, Halls. На добавлении и редактировании в конце крошек название зала. Вкладка Catalogs остаётся выделенной.

## Эссе — сущности

- **Зал:** название, адрес, необязательная ссылка на ролик YouTube или Vimeo. Ссылка — текст, не файл.
- **Файлы зала** — записи файлов этого зала (`../../03-architecture/files.md`). У записи есть индекс. В ответе зала они приходят в поле `images`, отсортированные по индексу. Картинка показывается картинкой. Видеофайл показывается тегом `video`. Адрес файла — `/files/halls/{id зала}/{id файла}` с расширением типа. Он публичный. Закрытие файла сессией — отдельная будущая тема.

Ссылка на YouTube или Vimeo в `images` не входит.

Индексы:

- Новый файл получает индекс, равный числу файлов зала в этот момент. У пустого зала первый файл получает 0. Несколько файлов за один раз получают индексы подряд в порядке добавления.
- Удаление файла переписывает индексы оставшихся подряд, с нуля.
- Перетаскивание меняет порядок на странице и вызывает отдельный запрос. Этот запрос обновляет индексы файлов этого зала. Сохранение названия, адреса и ссылки его не вызывает.

Файл загружается только на странице редактирования, когда зал уже сохранён. На странице создания галереи нет.

## Эссе — страницы

- **Halls** — корень подраздела. Список. Кнопки «Back» нет.
- **Добавление зала** — страница внутри Halls.
- **Редактирование зала** — страница внутри Halls. Здесь же галерея.
- **Trainers и Class types** — пустые страницы.

## Эссе — потоки по шагам

Тексты в каноне на английском. Тексты, помеченные «фиксировано», вставляются как есть. Внешний вид списков и форм: `../../02-design/flow-design.md`. Сообщения о результате и ошибках действия — как в `overview.md`.

### Поток 1. Список залов

Строка действий: слева поиск, справа «Add hall». Поиск — подстрока названия зала без учёта регистра. Таблица. Столбцы: Name, Address; последний столбец — меню ⋮ с «Edit». «Back» нет. Строка вкладок раздела выделена на Catalogs. Вторая строка выделена на Halls.

- Пусто, когда залов нет: «No halls yet» с кнопкой «Add hall» (фиксировано).
- Пусто, когда поиск ничего не нашёл: «No halls found», подсказка «Change the search term to find what you're looking for.», кнопка «Reset search» (фиксировано).

### Поток 2. Добавление зала

Поля: «Name», «Address», «Video link». «Name» и «Address» обязательны. «Video link» можно не заполнять. Если ссылка заполнена, это адрес YouTube или Vimeo. Кнопки «Back» и «Save». «Back» возвращает в список без сохранения. Галереи нет. Вторая строка вкладок выделена на Halls.
- Ошибки у поля (фиксировано): «Enter a name»; «Enter an address»; «Enter a YouTube or Vimeo link».
- Успех: возврат в список, сообщение «Hall added» (фиксировано).

### Поток 3. Редактирование зала

Те же поля, заполнены. Кнопки «Back» и «Update». «Back» возвращает в список без сохранения. Ниже полей — галерея. Вторая строка вкладок выделена на Halls.

Те же ошибки полей и те же правила ссылки, что в потоке 2. Успех: возврат в список, сообщение «Hall updated» (фиксировано).

Галерея показывает `images` по индексу. Картинка — картинкой, видеофайл — тегом `video`. Кнопка добавления файла — «Add file» (фиксировано). Файл можно добавить и удалить. Добавление ставит индекс по правилу из раздела «Сущности». У превью справа вверху красный крестик. Нажатие открывает окно «Remove file?», текст «This file will be removed from the hall. You can add it again at any time», кнопки «Remove» и «Cancel» (фиксировано). «Cancel» закрывает окно, файл остаётся. Файл удаляется только после «Remove». Успех: «File removed» (фиксировано). Удаление переписывает индексы. Файлы можно перетаскивать. После перетаскивания вызывается отдельный запрос обновления индексов.

### Поток 4. Пустые вкладки

Trainers и Class types открываются пустой страницей. Выделена их вкладка во второй строке. Вкладка Catalogs остаётся выделенной.

## Агент — правила

- Верхняя строка вкладок не получает отдельных вкладок залов, тренеров и видов занятий.
- Вторая строка: Halls, Trainers, Class types. Список и формы есть только у Halls. Две другие вкладки пустые.
- Зал: название, адрес, необязательная ссылка на YouTube или Vimeo.
- Галерея только на редактировании уже сохранённого зала. В ответе зала поле `images` отсортировано по индексу.
- Индекс нового файла равен числу файлов зала. Удаление и перетаскивание переписывают индексы подряд с нуля. Перетаскивание вызывает отдельный запрос. Сохранение полей зала индексы не меняет.
- Видеофайл показывается тегом `video`. Его адрес — публичный `url` файла. Ссылка на YouTube или Vimeo в галерею не входит.
- Поиск списка — подстрока названия без учёта регистра.
- Фиксированные тексты: «Hall added», «Hall updated», «Enter a name», «Enter an address», «Enter a YouTube or Vimeo link», «Add file», «Remove file?», «This file will be removed from the hall. You can add it again at any time», «Remove», «Cancel», «File removed», «New hall».
- Удаления зала в этом документе нет.
- Менять документ только после явного согласия владельца.
