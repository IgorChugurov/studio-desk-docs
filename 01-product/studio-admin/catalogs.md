# Каталоги админки студии — залы, тренеры, виды занятий

**Scope:** раздел Catalogs админки студии: залы, тренеры и виды занятий.
**Last verified:** 2026-10-09

## Эссе — что это

Catalogs — раздел админки студии. Его видят владелец и администратор. Верхняя строка вкладок не меняется: Catalogs остаётся одной вкладкой (`overview.md`).

Под ней, в области страницы, вторая строка: Halls, Trainers, Class types. У каждой вкладки свой список и свои формы. Вкладка Catalogs остаётся выделенной.

Хлебные крошки: название студии, Catalogs, затем Halls, Trainers или Class types. На добавлении в конце крошек «New hall», «New trainer» или «New class type» (фиксировано). На редактировании в конце название записи.

## Эссе — сущности

- **Зал:** название, адрес, описание, необязательная ссылка на ролик YouTube или Vimeo. Описание и ссылку можно не заполнять. Ссылка — текст, не файл.
- **Тренер:** имя, описание, ссылка на Instagram и ссылка на TikTok. Описание и обе ссылки можно не заполнять. Если ссылка заполнена, это адрес этой сети. Почты, часов работы, ставки и промокода нет. Это карточка каталога. Вход сотрудника, который на неё ссылается, описан в `overview.md`.
- **Вид занятия:** название и описание. Описание можно не заполнять. Вместимости, признака «группа или один человек», длительности и цены нет. Их вводят, когда занятие ставят в расписание.
- **Файлы** записи каталога (`../../03-architecture/files.md`). У записи есть индекс. В ответе они приходят в поле `images`, отсортированные по индексу. Картинка показывается картинкой. Видеофайл показывается тегом `video`. Адрес публичный, с расширением типа:
  - зал: `/files/halls/{id зала}/{id файла}`;
  - тренер: `/files/trainers/{id тренера}/{id файла}`;
  - вид занятия: `/files/class-types/{id вида}/{id файла}`.
  Закрытие файла сессией — отдельная будущая тема.

Ссылка на YouTube или Vimeo в `images` не входит.

Индексы:

- Новый файл получает индекс, равный числу файлов этой записи в этот момент. У пустой записи первый файл получает 0. Несколько файлов за один раз получают индексы подряд в порядке добавления.
- Удаление файла переписывает индексы оставшихся подряд, с нуля.
- Перетаскивание меняет порядок на странице и вызывает отдельный запрос. Этот запрос обновляет индексы файлов этой записи. Сохранение полей записи индексы не меняет.

Файл загружается только на странице редактирования, когда запись уже сохранена. На странице создания галереи нет.

## Эссе — страницы

- **Halls** — корень подраздела. Список. Кнопки «Back» нет.
- **Добавление зала** — страница внутри Halls.
- **Редактирование зала** — страница внутри Halls. Здесь же галерея.
- **Trainers** — список тренеров. Добавление и редактирование — страницы внутри него. Кнопки «Back» на списке нет.
- **Class types** — список видов занятий. Добавление и редактирование — страницы внутри него. Кнопки «Back» на списке нет.

## Агент — правила

- Верхняя строка вкладок не получает отдельных вкладок залов, тренеров и видов занятий.
- Вторая строка: Halls, Trainers, Class types. У каждой свой список и свои формы.
- Зал: название, адрес, описание, необязательная ссылка на YouTube или Vimeo. Описание можно не заполнять.
