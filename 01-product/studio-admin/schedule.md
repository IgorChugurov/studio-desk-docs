# Расписание админки студии — раздел Schedule

**Scope:** раздел Schedule админки студии: шаблоны недели, занятия, показ расписания, действия с неделями и с занятием.
**Last verified:** 2026-10-14

## Эссе — что это

Schedule — раздел админки студии. Доступ по таблице в `overview.md`: владелец и администратор видят весь раздел, тренер — только свои занятия, бухгалтер раздела не видит. В этом срезе тренер свои занятия только смотрит. Что он может с ними делать (перенос, отмена, замена себя), решается после того, как готова поверхность администратора.

Расписание — это таблица занятий. Каждое занятие — отдельная запись (поля — в разделе «Сущности»). Занятие можно создать кликом по сетке в любой ещё не начавшийся день. Занятие, которое уже началось, создать нельзя. Будущее занятие можно изменить. Прошедшим занятие становится с момента начала по текущему времени. Прошедшее занятие заморожено.

Шаблоны недели — механизм, который держит разные варианты расписания и быстро размечает недели. Строки шаблона копируются в таблицу занятий. После копирования занятие от шаблона не зависит.

Управление расписанием — главная ежедневная работа администратора: переносы, замены, отмены, смена тренера, переход на другую сетку. Поэтому раздел должен быть простым и гибким.

Компоненты показа проектируются так, чтобы стать основой публичного расписания на сайте студии. Там клиенту нужны просмотр, поиск и запись на занятие. Сама публичная страница — отдельная тема.

## Эссе — границы среза

Входит:
- шаблоны недели и их строки;
- занятия, в том числе в виртуальном зале, с форматом онлайн или офлайн и с несколькими тренерами;
- ручная разметка недель: «наложить шаблон», «очистить недели», «заменить по шаблону»;
- создание, правка, перенос, отмена, снятие отмены, удаление и замена занятия;
- показ расписания в админке, в том числе на страницах зала и тренера в Catalogs.

Не входит:
- запись клиентов, посещение и списание с абонементов, абонементы, оплата тренера;
- лист ожидания, часы работы тренера;
- действия тренера со своими занятиями;
- публичная страница расписания на сайте студии;
- перетаскивание занятий мышью в сетке;
- автоматическое продление разметки (следующий этап, см. «Открытые вопросы»).

## Эссе — время

- Занятие проводится только в зале. У зала есть часовой пояс (`catalogs.md`).
- Дата и время начала занятия хранятся по часам зала. Реальный момент начала вычисляется из пояса зала на эту дату. Источник правды — дата и время по часам зала и пояс зала.
- Пояс зала можно поменять. Время занятий по часам зала не меняется, сетка перестраивается сама. Если из-за этого у тренера два занятия в один момент, сохранение зала отклоняется с указанием занятия.
- Время начала и длительность кратны 5 минутам. Длительность от 5 до 240 минут.
- Занятие кончается не позже 24:00 по часам зала. Занятий через полночь нет.
- Пересечения занятий проверяются по реальному моменту, а не по цифрам на часах.
- Расписание показывается в поясе просмотра. Сотрудник может его переключить. По умолчанию:
  - общий вид и вид тренера показываются в поясе студии;
  - вид одного зала показывается в поясе зала.
- Время в форме и в окне занятия — в поясе просмотра. В часы зала система переводит сама. Шаблон показывается и правится в поясе просмотра так же.
- Прошедшим занятие становится с момента начала по текущему времени.

## Эссе — сущности

- **Шаблон недели:** название и набор строк. Шаблонов несколько. Шаблон может описывать один зал или несколько. На одну неделю можно наложить несколько шаблонов.
- **Строка шаблона:** день недели, время начала по часам зала, длительность, зал, тренеры (один или несколько), вид занятия, «группа или один человек», формат, число мест.
- **Занятие:** зал, дата, время начала по часам зала, длительность, тренеры (один или несколько), вид занятия, «группа или один человек», формат, число мест, признак «отменено». Будущее и прошедшее определяются по текущему времени и не хранятся.
- **Цена.** У занятия нет цены (`catalogs.md`).
- **Формат.**
  - Одно значение из трёх: «офлайн», «доступно онлайн» (занятие идёт офлайн и онлайн одновременно), «только онлайн». В обычном зале по умолчанию «офлайн».
  - В виртуальном зале занятие всегда только онлайн. Если в форме зал сменили на виртуальный, формат становится «только онлайн», поле мест убирается.
  - Занятие «только онлайн» в обычном зале всё равно занимает зал.
- **Группа или один человек.** По умолчанию «группа», можно поменять.
- **Число мест.**
  - Группа: число мест задаётся для офлайна, целое число от 1. Онлайн без ограничения.
  - Один человек: участник один в любом формате, число мест не спрашивается.
- **Тренеры.** В форме предлагаются тренеры, связанные с выбранным видом занятия (`catalogs.md`). Если связанных тренеров нет, показываются все. Выбранные тренеры при смене вида не сбрасываются. Связь — только фильтр выбора: она не ограничивает уже стоящие занятия.
- **Длительность.** При выборе вида занятия в форму подставляется длительность вида по умолчанию (`catalogs.md`). Её можно поменять. Если сменить вид в форме, снова подставляется длительность нового вида.
- **Шаблон — штамп.** Правка и удаление шаблона не меняют уже созданные занятия. Правка и удаление занятия не меняют шаблон.

Инварианты:
1. Занятие проводится только в зале.
2. В зале в один момент не больше одного действующего занятия.
3. У тренера в один момент не больше одного действующего занятия, в любых залах. Если тренеров несколько, правило действует для каждого.
4. Занятия «встык» разрешены: одно кончается в 19:00, другое начинается в 19:00.
5. Отменённое занятие не занимает зал и тренеров.
6. Пересечения проверяет база данных. Два одновременных сохранения, которые нарушают правило, не проходят оба.
7. Внутри шаблона действуют те же правила: в один день недели строки одного зала не пересекаются, строки одного тренера тоже. Время строк сравнивается по цифрам в поясе просмотра. Проверка при сохранении строки.

## Эссе — страницы

Внутри Schedule вторая строка вкладок: Schedule и Templates. Вкладка Schedule в верхней строке остаётся выделенной.

- **Schedule** — корень раздела: компонент расписания на всю страницу.
- **Templates** — список шаблонов. Добавление и редактирование шаблона — страницы внутри него.

Хлебные крошки: на Schedule — название студии, Schedule; на Templates — название студии, Schedule, Templates. На добавлении шаблона в конце «New template» (фиксировано). На редактировании — название шаблона.

Компонент расписания также стоит на странице редактирования зала и на странице редактирования тренера в Catalogs, под галереей (`catalogs.md`). Там он уже отфильтрован по этому залу или тренеру, показывает недельную сетку и даёт те же действия с занятием.
- Есть выбор недели (стрелки и календарь) и переключатель пояса просмотра. Открывается текущая неделя.
- На странице зала есть фильтр по тренеру. Пояс просмотра по умолчанию — пояс зала.
- На странице тренера есть фильтр по залу. Пояс просмотра по умолчанию — пояс студии.
- Переключателя «Halls / Trainers» и кнопок действий с неделями нет.
- Клик по пустому месту открывает форму занятия с уже выбранным залом или тренером.

## Эссе — показ расписания

Один компонент показа. В админке он даёт создание и правку, на будущем сайте — только просмотр.

Виды:
- **Залы столбцами.** Строки — часы. Неделя идёт вниз: блок понедельника с часами, под ним блок вторника и так далее.
- **Тренеры столбцами.** Устроен так же. Занятие с несколькими тренерами показывается в столбце каждого.
- **Один зал или один тренер.** Обычная недельная сетка: столбцы — дни, строки — часы. Если выбран зал, на карточке видны тренеры. Если выбран тренер, на карточке виден зал.

Переключатель «залы или тренеры столбцами».

Фильтры: зал, тренер, вид занятия. В каждом фильтре одно значение или «All», по умолчанию «All». Фильтр по одному залу или одному тренеру включает недельную сетку. Если выбраны и зал, и тренер, видна недельная сетка этого зала, и в ней только занятия этого тренера. При смене недели фильтры сохраняются. При уходе со страницы сбрасываются.

Диапазон часов: в блоке дня видны часы 08:00–22:00. Часы 00:00–08:00 и 22:00–24:00 — узкие полоски сверху и снизу. Клик по полоске раскрывает эти часы, по ним можно кликать, чтобы создать занятие. Если в этих часах на неделе есть занятие, полоска раскрыта сразу. Диапазон один на всю неделю.
- Блок дня сворачивается кликом по заголовку с датой. По умолчанию все дни раскрыты. На новой неделе все дни снова раскрыты.
- Что свёрнуто и раскрыто у ночных полосок, браузер запоминает для этого сотрудника. Свёрнутые дни не запоминаются.
- В недельной сетке одного зала или тренера ночные полоски работают так же. Дни там — столбцы, их не сворачивают. Сегодняшний столбец выделен.

Пустые столбцы при включённом фильтре (по виду занятия или по тренеру) скрываются, без фильтра видны все.

Отменённое занятие:
- Если на месте есть действующее занятие, рядом одна узкая полоска, сколько бы ни было отменённых.
- Если действующего нет, на месте карточка с пометкой «Cancelled» (фиксировано).
- Клик по полоске или по карточке открывает модальное окно со списком всех отменённых занятий на этом месте: в этом столбце и пересекающихся по времени. По каждому видны вид занятия, время, зал, тренеры, формат и число мест.
- У будущего отменённого в строке списка кнопки «Restore» и «Delete» с теми же подтверждениями и ошибками, что в потоке 4. У прошедшего отменённого кнопок нет, только информация.

Неделю можно выбрать в календаре на любую дату, в том числе далеко вперёд. Открывается текущая неделя. В виде с днями вниз страница прокручена к блоку сегодняшнего дня.

Над сеткой справа кнопки «Apply template», «Clear weeks», «Replace with template». Их видят владелец и администратор. Тренер их не видит.

Мобильная версия: столбцы прокручиваются по горизонтали, столбец часов остаётся на месте.

## Эссе — что решает дизайнер

Внешний вид — по `../../02-design/flow-design.md`.

Дизайнер не меняет:
- виды сетки и расположение блоков;
- свёрнутые ночные часы и сворачивание дня;
- показ отменённого занятия: полоска рядом с действующим или карточка «Cancelled»;
- фиксированные тексты.

Дизайнер решает:
- цвета, размеры, шрифты;
- как выглядит карточка занятия и полоска отменённого;
- как выглядят свёрнутые полоски и заголовок дня;
- вид окна конфликтов и окна списка отменённых.

На карточке занятия видно:
- вид занятия;
- время начала и конца;
- тренеры, когда сетка по залам;
- зал, когда сетка по тренерам;
- формат, если он не обычный офлайн;
- «one person» (фиксировано), если занятие не групповое.

### Для будущей публичной страницы

Не входит в срез. Записано, чтобы компонент показа это допускал.
- Только просмотр.
- Переключатель «залы или тренеры столбцами» есть.
- Диапазон часов один на всю неделю и вычисляется по занятиям видимой недели: от самого раннего начала до самого позднего конца.
- Пустые столбцы скрываются всегда.
- Пояс просмотра виден в навбаре и переключается. Первый показ идёт в поясе студии. Затем страница определяет пояс браузера, переключается на него и запоминает выбор в cookie.

## Эссе — действия с неделями

Разметка недель только ручная. Есть три действия.

**Наложить шаблон.** Администратор выбирает шаблон и недели (одну или несколько подряд, на любой срок). Система строит занятия по строкам шаблона и сверяет их с уже стоящими.
- Если такое же занятие уже стоит, оно пропускается. Это не конфликт. «Такое же» — совпадают все поля: зал, дата, время, длительность, вид, тренеры, «группа или один человек», формат, число мест. Признак «отменено» не важен: отменённое такое же занятие тоже пропускается и остаётся отменённым.
- Если конфликтов нет, занятия создаются сразу.
- Если есть конфликты по залу или по тренеру, администратор видит их список. Каждая строка — занятие из шаблона и все существующие занятия, с которыми оно пересекается, с причиной. Для каждого занятия из шаблона один выбор: «оставить существующее» (занятие из шаблона не создаётся) или «применить новое» (все пересекающиеся с ним существующие занятия удаляются, занятие из шаблона создаётся). Есть выбор сразу для всех.
- Сохранение идёт целиком: либо применено всё, либо ничего.

**Очистить недели.** Администратор выбирает недели и залы (все или отдельные). Будущие занятия в них удаляются. Перед удалением видно, сколько занятий удалится, нужно подтверждение.

**Заменить по шаблону.** Очистить и наложить за один шаг. Администратор выбирает шаблон, недели и что очищать: только залы шаблона или все залы. Перед выполнением видно, сколько занятий удалится и сколько создастся. Конфликты по тренеру с занятиями в других залах решаются так же, как при наложении.

Уже начавшиеся занятия эти действия не затрагивают. Создаются только занятия, которые ещё не начались. Выбор недель начинается с текущей.

## Эссе — действия с занятием

- **Создать.** Клик по пустому месту сетки открывает модальное окно. В нём уже стоят дата и время ячейки, а также зал или тренер столбца. Администратор заполняет остальное. Создать занятие можно в любой ещё не начавшийся день. Занятие, которое уже началось, создать нельзя.
- **Править.** Клик по занятию открывает модальное окно. Можно менять время, дату, зал, длительность, тренеров, формат и число мест. Вид занятия здесь не меняется.
- **Прошедшее занятие** (уже началось), в том числе отменённое, открывается только для просмотра. Действий нет.
- **Будущее отменённое занятие:** доступны «Restore», «Delete» и закрыть окно. Поля менять нельзя.
- **Сохранение.** На время сохранения экран затемняется. Бэкенд проверяет условия, в том числе пересечения. Если всё в порядке, занятие сохраняется и окно закрывается. Если нет, окно остаётся открытым, и видна причина отказа с указанием, с чем конфликт.
- **Отменить.** Занятие остаётся в сетке с пометкой «Cancelled» и освобождает зал и тренеров.
- **Снять отмену.** Можно, если на этом времени не стоит другое занятие и нет пересечения по залу и тренерам.
- **Удалить.** Занятие исчезает из расписания.
- **Заменить.** Смена вида занятия — это отмена и новое занятие. Кнопка «Replace» открывает форму нового занятия — ту же, что при создании. Всё заполнено со старого занятия, кроме вида. Менять можно всё. При выборе вида длительность берётся из нового вида. «Back» возвращает в окно старого занятия. При сохранении старое занятие отменяется, новое создаётся. Это одно действие: если новое занятие не проходит проверку, старое тоже не отменяется. Новое занятие со старым не связано.

## Эссе — потоки по шагам

Тексты в каноне на английском. Тексты, помеченные «фиксировано», вставляются как есть. Внешний вид — по `../../02-design/flow-design.md`. Сообщения о результате и ошибках действия — как в `overview.md`. У каждого экрана есть мобильная версия.

### Поток 1. Просмотр расписания

Вкладка Schedule. Сверху выбор недели (стрелки и календарь), переключатель «Halls / Trainers», фильтры: зал, тренер, вид занятия, пояс просмотра. Ниже — вид по правилам раздела «Показ расписания».
- Пустая неделя: видны часы 08:00–22:00, ночные полоски свёрнуты, по сетке можно кликать.
- Тренер видит только свои занятия, без действий.

### Поток 2. Создание занятия

Клик по пустому месту. Модальное окно «New class» (фиксировано). Поля: «Date», «Start time», «Hall», «Class type», «Duration», «Trainers», «Group / One person», «Places» (только для группы с офлайном), «Format» с вариантами «Offline», «Offline and online», «Online only» (фиксировано). В виртуальном зале «Format» только для чтения со значением «Online only». Кнопки «Save» и «Back».
- Ошибки у поля (фиксировано): «Select a date»; «Select a hall»; «Select a class type»; «Select at least one trainer»; «Enter a time in steps of 5 minutes»; «Enter a duration from 5 to 240 minutes in steps of 5»; «Enter the number of places»; «A class must end by midnight».
- Время в текстах пишется как `HH:MM`, 24 часа.
- Ошибки пересечения (фиксировано): «The hall is busy at this time: {class type} {start}–{end}»; «{trainer} has another class at this time: {hall} {start}–{end}».
- Успех: окно закрывается, занятие в сетке, сообщение «Class added» (фиксировано).

### Поток 3. Правка занятия

Клик по занятию. Модальное окно с заполненными полями. «Class type» только для чтения. Кнопки «Save», «Cancel class», «Replace», «Delete», «Back».
- Прошедшее занятие: все поля только для чтения, кнопка «Back» закрывает окно.
- Будущее отменённое занятие: поля только для чтения, кнопки «Restore», «Delete», «Back».
- Ошибки — как в потоке 2.
- Успех: окно закрывается, сообщение «Class updated» (фиксировано).

### Поток 4. Отмена, снятие отмены, удаление

- «Cancel class» открывает окно «Cancel class?», текст «The class stays in the schedule marked as cancelled», кнопки «Cancel class» и «Back» (фиксировано). Успех: «Class cancelled» (фиксировано).
- У отменённого занятия в окне есть кнопка «Restore». Ошибки пересечения — как в потоке 2. Успех: «Class restored» (фиксировано).
- «Delete» открывает окно «Delete class?», текст «The class will be removed from the schedule», кнопки «Delete» и «Back» (фиксировано). Успех: «Class deleted» (фиксировано).

### Поток 5. Замена занятия

«Replace» в окне занятия открывает форму нового занятия с теми же полями, что в потоке 2. Всё заполнено со старого занятия, кроме «Class type». Менять можно все поля. Длительность при выборе вида берётся из вида. Кнопки «Save» и «Back». «Back» возвращает в окно старого занятия.
- Ошибки — как в потоке 2. При ошибке старое занятие не отменяется.
- Успех: старое отменено, новое создано, сообщение «Class replaced» (фиксировано).

### Поток 6. Шаблоны

Вкладка Templates — корень подраздела, «Back» нет. Строка действий: справа «Add template». Таблица: Name; последний столбец — меню ⋮ с «Edit» и «Delete».
- Пусто: «No templates yet» с кнопкой «Add template» (фиксировано).
- Добавление: поле «Name», кнопки «Back» и «Save». Ошибка (фиксировано): «Enter a name». Название шаблона не повторяется в студии. Успех: открывается редактирование нового шаблона, сообщение «Template added» (фиксировано).
- Редактирование: поле «Name», кнопки «Back» и «Update»; ниже недельная сетка без дат. «Back» и успешный «Update» возвращают в список шаблонов. Клик по пустому месту открывает окно строки с теми же полями, что в потоке 2, но вместо даты «Day of week». Клик по строке открывает её правку: менять можно все поля, включая вид; есть кнопка «Delete» с подтверждением. Ошибки — как в потоке 2, плюс «Select a day of week» (фиксировано). Успех правки названия: «Template updated» (фиксировано).
- Залы шаблона — залы, которые есть в его строках.
- Удаление: окно «Delete template?», текст «Classes already created from this template stay in the schedule», кнопки «Delete» и «Back» (фиксировано). Успех: «Template deleted» (фиксировано).

### Поток 7. Наложить шаблон

Кнопка «Apply template». Окно: «Template», «Weeks»: поля «From» и «To». Каждое открывает календарь, клик по дню выбирает его неделю. Недели раньше текущей выбрать нельзя. Кнопки «Apply» и «Back».
- Без конфликтов: сообщение «Template applied: {n} class added» или «Template applied: {n} classes added» (фиксировано). Если создавать нечего, {n} равен 0.
- С конфликтами: окно «Conflicts». В каждой строке «From template» и все пересекающиеся с ним «Existing» с причиной, один выбор «Keep existing» или «Apply new». Кнопки «Keep all existing», «Apply all new», «Apply», «Back» (фиксировано). «Back» возвращает в первое окно с сохранёнными полями. После «Apply» то же сообщение «Template applied: {n} classes added».

### Поток 8. Очистить недели

Кнопка «Clear weeks». Окно: «Weeks» (поля «From» и «To», как в потоке 7), «Halls» (все или выбранные). Подтверждение «Clear weeks?», текст «{n} class will be deleted» или «{n} classes will be deleted», кнопки «Clear» и «Back» (фиксировано). Если удалять нечего, {n} равен 0. Успех: «Weeks cleared» (фиксировано).

### Поток 9. Заменить по шаблону

Кнопка «Replace with template». Окно: «Template», «Weeks», «Clear» («Template halls» или «All halls»). Подтверждение «Replace with template?», текст «{n} class will be deleted and {m} created» или «{n} classes will be deleted and {m} created», кнопки «Replace» и «Back» (фиксировано). «Weeks» — поля «From» и «To», как в потоке 7. Конфликты по тренеру — окно «Conflicts», как в потоке 7. Успех: «Weeks replaced» (фиксировано).

## Агент — правила

- Занятие всегда в зале. Дата и время хранятся по часам зала, реальный момент вычисляется из пояса зала. Пояс зала можно поменять: время по часам зала остаётся, при пересечении у тренера сохранение зала отклоняется.
- Время в форме, в окне занятия и в шаблоне — в поясе просмотра; перевод в часы зала автоматический.
- Время начала и длительность кратны 5 минутам. Длительность от 5 до 240 минут. Занятие кончается не позже 24:00 по часам зала.
- В зале и у каждого тренера в один момент не больше одного действующего занятия. «Встык» разрешено. Отменённое не занимает. Проверка в базе. Внутри шаблона те же правила, время строк сравнивается по цифрам.
- У занятия признак «отменено», других статусов нет. Прошедшее — уже начавшееся по текущему времени; оно заморожено, в том числе отменённое.
- У занятия несколько тренеров. Связь «тренер — виды занятий» — только фильтр выбора в форме. Нет связанных — показываются все. Выбранные при смене вида не сбрасываются.
- При выборе вида подставляется его длительность, её можно поменять.
- Формат — одно из трёх: офлайн, «доступно онлайн», «только онлайн». В виртуальном зале только онлайн, при смене зала на виртуальный формат и места меняются сами. По умолчанию «группа». Число мест — целое от 1, только для группы с офлайном. Один человек — один участник.
- Цены у занятия нет.
- Шаблон — штамп: правка и удаление шаблона не меняют созданные занятия. Название шаблона уникально в студии.
- Разметка недель только ручная: «наложить шаблон», «очистить недели», «заменить по шаблону». Выбор недель с текущей. Начавшиеся занятия не затрагиваются, создаются только ещё не начавшиеся. «Такое же занятие» — совпадают все поля, признак «отменено» не важен.
- При конфликте наложения один выбор на занятие из шаблона; «применить новое» удаляет все пересекающиеся с ним существующие занятия.
- В окне занятия вид не меняется. Смена вида — только через «Replace»: отмена старого и создание нового одним действием, новое со старым не связано.
- Отмена и удаление — с подтверждением. Снять отмену можно, если нет пересечения по залу и тренерам. У будущего отменённого — только «Restore» и «Delete».
- Один компонент показа для админки, страниц зала и тренера и будущего сайта. В админке видны часы 08:00–22:00, ночные часы — раскрывающиеся полоски, день сворачивается по заголовку. Открывается текущая неделя, прокрутка к сегодняшнему дню.
- Фильтр принимает одно значение или «All». На странице зала — фильтр по тренеру, на странице тренера — фильтр по залу. Кнопок действий с неделями там нет.
- Отменённые на одном месте — одна полоска или карточка «Cancelled»; клик открывает список. У будущего отменённого в списке «Restore» и «Delete».
- Вторая строка вкладок раздела: Schedule и Templates.
- Тренер в этом срезе только смотрит свои занятия, без действий.
- Не добавлять: перетаскивание, автопродление, запись, посещение, списание, цену у занятия, занятия через полночь.
- Менять документ только после явного согласия владельца.
