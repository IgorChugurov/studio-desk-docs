# Backend brief feedback — Platform admin

Записи реализации по `backend-brief.md`. Канон темы отсюда не меняется.

## 1. Исследование: доставка кодов на e-mail

**Решение, согласовано с владельцем 2026-10-03.** Провайдер — Resend, бесплатный план. Тот же аккаунт, что уже шлёт почту сайта `our-site` (ветка `main`: пакет `resend`, адрес отправителя `contact@axondigital.xyz`). Отдельный провайдер не заводим.

Бесплатный план: 3 000 писем в месяц и не больше 100 в день, без абонентской платы. Для одного администратора платформы этого достаточно. Цены сверены 2026-10-03 по страницам провайдеров; остальные варианты (Brevo, Mailgun, Postmark, Scaleway, Amazon SES) отклонены из‑за подписи в письме, слишком малого лимита или отсутствия бесплатного лимита для нового аккаунта.

**Адрес отправителя кодов:** `StudioDesk <noreply@axondigital.xyz>`. Домен `axondigital.xyz` в Resend уже подтверждён сайтом `our-site`, отдельный поддомен не нужен.

**Ключ.** Для StudioDesk — отдельный ключ API в том же аккаунте Resend. Ключ сайта `our-site` не копируется. Ключ живёт только в `.env` на машине разработчика и на сервере. В репозиторий, образ, логи CI и чат он не попадает.
