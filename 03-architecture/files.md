# Файлы

**Scope:** где StudioDesk хранит загруженные файлы и как браузер их получает.
**Last verified:** 2026-10-08

## Эссе — что это

Загруженный файл лежит на диске. В базе хранится запись о нём: где он лежит, к какой сущности относится и какой у него индекс среди файлов этой сущности. Сам файл в базе не хранится. Индексы одной сущности идут подряд с нуля. Новый файл получает индекс, равный числу файлов сущности в этот момент. Удаление переписывает индексы оставшихся подряд, с нуля. Перетаскивание вызывает отдельный запрос, который обновляет индексы файлов этой сущности. Сохранение остальных полей сущности индексы не меняет.

Фронтенд файл к себе не копирует. Браузер запрашивает адрес API, бэкенд читает файл из папки и отдаёт его.

## Эссе — где лежит файл

Папка задаётся настройкой и в обоих местах одна и та же для кода.

- **Локально.** Бэкенд запущен на компьютере (`pnpm start:dev`) и пишет в `studio-desk-backend/storage`. Эта папка в git не попадает. Nginx нет: браузер ходит к бэкенду напрямую.
- **На сервере.** Файлы лежат в `/opt/studio-desk/files`. Эта папка подключена к контейнеру бэкенда и внутри него видна как `/files`. Контейнер при деплое заменяется, папка на диске остаётся.

## Эссе — адрес

`{id}` — идентификатор записи файла.

- Локально: `http://localhost:3000/api/files/{id}`
- На сервере: `https://api.studio-desk.axondigital.xyz/api/files/{id}`

На сервере nginx передаёт этот запрос бэкенду так же, как остальные запросы API. Отдельной раздачи папки через nginx нет.

## Эссе — когда файл загружается

Сначала сохраняется сущность. Файл загружается на странице редактирования, когда у сущности уже есть id. На странице создания загрузки нет.

## Эссе — как связано

- Устройство бэкенда: `backend-structure.md`.
- Сервер, `/opt/studio-desk/` и nginx: `deployment.md`.

## Агент — правила

- Файл хранится на диске. В базе — запись: где файл лежит, к какой сущности относится и его индекс. Индексы одной сущности идут подряд с нуля. Удаление и перетаскивание переписывают их. Перетаскивание — отдельный запрос. Сохранение остальных полей сущности индексы не меняет.
- Локальная папка — `studio-desk-backend/storage`, в git её нет. Серверная папка — `/opt/studio-desk/files`, внутри контейнера `/files`.
- Браузер получает файл по `/api/files/{id}` на хосте API.
- Nginx файл с диска не отдаёт, запрос идёт в бэкенд.
- Загрузка только после сохранения сущности, на странице редактирования.
- Менять документ только после явного согласия владельца.

## Открытые вопросы

- Кто может открыть `/api/files/{id}`: любой посетитель или только вошедший человек.
- Адрес запроса, которым файл загружается.
